# Landing Page Responsiva — Demo de Portfolio

Proyecto de demostración desarrollado con **HTML, CSS y JavaScript puro** (sin frameworks), como muestra de habilidades frontend para mi portfolio.

## 🔗 Demo en vivo
> [Ver demo](https://rodrigodevAR.github.io/landing-page-demo) *(disponible al publicar en GitHub Pages)*

## ✨ Características

- **Diseño 100% responsivo** — mobile, tablet y desktop
- **Navbar** fija con efecto glassmorphism al hacer scroll
- **Menú hamburger** animado para móviles
- **Hero** con gradiente y animaciones CSS puras
- **Formulario de contacto** con validación en tiempo real (JS vanilla)
- **Scroll animations** con IntersectionObserver
- **Smooth scroll** con offset para navbar fija
- **Accesibilidad** básica (aria-labels, semántica HTML)

## 🛠️ Tecnologías

| Tecnología | Uso |
|---|---|
| HTML5 | Estructura semántica |
| CSS3 | Estilos, animaciones, responsive (Flexbox + Grid) |
| JavaScript (ES6+) | Interactividad, validación, IntersectionObserver |
